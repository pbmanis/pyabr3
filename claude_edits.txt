CALIBRATION PROGRAM
-------------------
Ported from the no-globals branch (0.5 s tones, 0.75 s records, 25-75% measurement window,
40 and 20 kHz notch filters, 1/5 octave bands, steepness 0.9, maxdB from the bandpass level,
noise floor mode). The GUI prompts for the manual settings before each run.

Output files, in the folder of "calfile" in the configuration:
  frequency_<speaker>.cal, microphone_<mic>.cal, chk75db_<speaker>.cal
  calibration_history/<name>_<dd-Mon-yyyy_HH-MM-SS>.cal
  Noise_Measure_<yyyy.mm.dd_HH.MM.SS>.csv
Differences from MATLAB: history names include the time, so a second calibration on the
same day does not replace the first, and DateTime is stored as text.

Added safeguards: a speaker run is refused if the preamp gain differs from the microphone
calibration file; a warning is logged for frequencies inside a notch filter.

Checked against stored MATLAB files: the SPL and microphone sensitivity formulas reproduce
the saved values to within 1e-9, and the file fields match in name and order.


VIEWERS
-------
Calibration tab: raw calibration (max SPL, cosinor, bandpass) and the 75 dB check, both with
the noise floor. The check shown is the first one made after the calibration on the same
day. Times come from the MAT-file header, not the file system, because file system times
change when files are moved. Of the 24 calibrations in abr_data/calibration_history, 21
find a check. Two have a check made just before the calibration; by decision these are not
shown.

Data viewer:
  .p    Opening one trial loads the whole recording. Stacked averages by level, single
        trial view, and Display radio buttons: Average only, Average with SD, Average with
        individual traces (at most 100 drawn per level; the SD uses all trials).
        Averages match analyze_abr on real click, tone and interleaved data (1e-15 uV).
  .pkl  Threshold summaries (all_tone_map_data.pkl), or any numeric arrays.
  .txt  MATLAB runs. Any file of a run loads it, with a list of the runs in that folder.
        Matches ABRPlotting ABR_Reader.read_dataset on real runs (3e-6 uV).
This viewer is for on-line inspection. Full analysis is done with other code.

DECISIONS
---------
- 104 dB calibrator: fix after MATLAB validation (see Open Items).
- All speakers kept. MF1-family speakers use 20 dB attenuation, as in no-globals abr4.m.
- Calibrations are not reloaded automatically; use Read Cal File.
- MATLAB-era recordings: the text files are the data of record. Assume 100 kHz for recent
  data (it may have been 50 kHz several years ago).
- Calibration files in the older formats (11 files in abr_data/calibrations_pre-2018918)
  give a "could not read" message.
