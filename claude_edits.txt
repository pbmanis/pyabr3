CALIBRATION PROGRAM
-------------------
Ported from the no-globals branch (0.5 s tones, 0.75 s records, 25-75% measurement window,
40 and 20 kHz notch filters, 1/5 octave bands, steepness 0.9, maxdB from the bandpass level,
noise floor mode). The GUI prompts for the manual settings before each run.

Output files, in the folder of "calfile" in the configuration:
  frequency_<speaker>.cal, microphone_<mic>.cal, chk75db_<speaker>.cal
  calibration_history/<name>_<dd-Mon-yyyy_HH-MM-SS>.cal
  Noise_Measure_<yyyy.mm.dd_HH.MM.SS>.csv
Differences from MATLAB: history names include the time, so a second calibration on the
same day does not replace the first, and DateTime is stored as text.

Added safeguards: a speaker run is refused if the preamp gain differs from the microphone
calibration file; a warning is logged for frequencies inside a notch filter.

Checked against stored MATLAB files: the SPL and microphone sensitivity formulas reproduce
the saved values to within 1e-9, and the file fields match in name and order.


VIEWERS
-------
Calibration tab: raw calibration (max SPL, cosinor, bandpass) and the 75 dB check, both with
the noise floor. The check shown is the first one made after the calibration on the same
day. Times come from the MAT-file header, not the file system, because file system times
change when files are moved. Of the 24 calibrations in abr_data/calibration_history, 21
find a check. Two have a check made just before the calibration; by decision these are not
shown.

Data viewer:
  .p    Opening one trial loads the whole recording. Stacked averages by level, single
        trial view, and Display radio buttons: Average only, Average with SD, Average with
        individual traces (at most 100 drawn per level; the SD uses all trials).
        Averages match analyze_abr on real click, tone and interleaved data (1e-15 uV).
  .pkl  Threshold summaries (all_tone_map_data.pkl), or any numeric arrays.
  .txt  MATLAB runs. Any file of a run loads it, with a list of the runs in that folder.
        Matches ABRPlotting ABR_Reader.read_dataset on real runs (3e-6 uV).
This viewer is for on-line inspection. Full analysis is done with other code.

DECISIONS
---------
- 104 dB calibrator: fix after MATLAB validation (see Open Items).
- All speakers kept. MF1-family speakers use 20 dB attenuation, as in no-globals abr4.m.
- Calibrations are not reloaded automatically; use Read Cal File.
- MATLAB-era recordings: the text files are the data of record. Assume 100 kHz for recent
  data (it may have been 50 kHz several years ago).
- Calibration files in the older formats (11 files in abr_data/calibrations_pre-2018918)
  give a "could not read" message.

BUGS FIXED
----------
- Every saved file stored the Subject ID as "testing". Start Acquisition now requires an
  ID (and refuses \ / : * ? " < > |, since it is part of a directory name). Test
  Acquisition saves nothing and needs no ID.
- A repeat of a stimulus type on one day overwrote the first, unless the files had been
  moved; datapath was ignored. Files now go to
    <datapath>/<date>-<Subject ID>_<serial>/<protocol>/
  with the serial from 000, as in acq4. Different protocols on one subject share _000; a
  repeat of a protocol goes to _001. File names are unchanged.
- Each acquisition started another Presenter.run loop. The extra loop died on the "NIDAQ
  task has not been released" check, skipping a repetition. A loop now starts only if none
  is running, so a loop that died on an error is replaced by the next acquisition.
- interleaved_plateau stored one waveform entry per level, so it ran nreps sweeps per level
  (4608 instead of 512 for interleaved_plateau), and it played the entry without the final
  scaling. Levels were low by the smallest attenuation (about 2.9 dB for
  interleaved_plateau and 43 dB for interleaved_plateau_low, with frequency_MF1.cal).
- The on-line average was not reset between click or tone stimuli; only the plot was
  cleared. It now restarts at each stimulus. Interleaved protocols average all sweeps.
- The Parameters panel accepted edits and discarded them, and its limits clamped the
  displayed values. It is now read-only and shows the true values.
- Tone pips above the calibrated maximum were sent with negative attenuation and no warning.
  Tone pips, interleaved protocols and clicks are now all checked when Start or Test is
  pressed, and a message lists every level that cannot be reached.
- The on-line plots were labeled msec and uV but drawn in s and V at the amplifier output.
  They are now drawn in msec and uV at the electrodes (gain 10,000), and the stimulus plot
  in msec. Saved data remain in volts at the amplifier output.
- Mode alternated between Finished and Running after a protocol ended. It now stays at
  Finished until the next acquisition, and Stop is not needed after a protocol ends.
- Freq (kHz) in the Status group showed Hz. It now shows kHz.
- Each level and frequency shown in the Status group was copied into the protocol's
  default_spl and default_frequency. The Status group no longer alters the protocol. Files
  saved earlier may hold the last displayed values in those two fields. The stimuli were
  not affected, since the defaults are used only when a protocol has no lists.

DECISIONS
---------
- nreps is the sweep count for the whole protocol for interleaved_plateau, and per level
  for clicks and for basic tone presentations.
- Protocols are used as saved. Changes are saved as a new protocol.
- interleaved_ramp and interleaved_random stay disabled and may be re-enabled later.
- Amplifier gain is 10,000. It cannot be read from the amplifier, so it is an entered value.
- RP2.1 In1 takes the ABR and In2 the microphone.
- The RZ5D is not used here: it cannot produce the output frequency for tones above 90 kHz.
